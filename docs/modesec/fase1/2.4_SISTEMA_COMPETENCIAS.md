## 4. Las tres unidades — contenidos y criterios de evaluación (§6, p. 6-21)

### Unidad 1: Introducción a la Algoritmia (p. 6-9) — 6 semanas

**Nivel de comprensión esperado (p. 6):** "Uniestructural y Multiestructural: Los estudiantes
podrán identificar y describir los conceptos básicos de la algoritmia, relacionarlos con el
desarrollo web y empezar a aplicarlos en la resolución de problemas sencillos, apoyándose en
herramientas de IA para la ideación, el análisis y la generación de código."

**Contenidos (p. 6-7):**
- Conceptos básicos: definición de algoritmo, características, tipos.
- Estructuras de control: secuencial, condicional, iterativa.
- Representación de algoritmos: diagramas de flujo, pseudocódigo.
- Variables, constantes, operadores, expresiones.
- Introducción al desarrollo web: HTML (estructura básica de una página web), CSS (estilos y
  diseño de páginas web), JavaScript (introducción a la programación web).
- Aplicaciones de la algoritmia en la educación: ejemplos de páginas web educativas, recursos
  educativos digitales que utilizan algoritmos.
- Introducción a la IA en el desarrollo web y la educación: conceptos básicos de IA (aprendizaje
  automático, procesamiento del lenguaje natural), herramientas de IA para la generación de
  código y diagramas de flujo (p. ej., GitHub Copilot).

**Criterios de evaluación / indicadores (p. 6-9):**
- `RA-203413-U1-E1`: "Los estudiantes crearán el diseño de una plantilla web básica utilizando
  HTML5, donde deberán incorporar elementos como encabezados, párrafos, enlaces y listas,
  aplicando lógica de programación para estructurar la página de manera coherente y cumplir con
  las buenas prácticas de codificación."
- `RA-203413-U1-E2` ("Mejora Estética de la Plantilla Web"): "Los estudiantes tomarán la plantilla
  web creada en la actividad anterior y mejorarán su estética **sin utilizar CSS**. Deberán
  utilizar recursos disponibles en HTML5 para mejorar la presentación visual de la página, como
  la selección cuidadosa de elementos y atributos."
- `RA-203413-U1-E3`: "Los estudiantes recibirán una plantilla web con problemas estructurales,
  como elementos desordenados o con errores visuales. Deberán aplicar su lógica de programación y
  conocimientos de HTML5 para identificar y resolver estos problemas."

**Evidencias e instrumentos (p. 6):** Plantilla Web creada y publicada en el Repositorio en
GitHub · Documentación de ejercicios enviados a CINTIA · Prueba tipo Saber Pro.

---

### Unidad 2. Desarrollo web (p. 10-18) — 6 semanas

**Nivel de comprensión esperado (p. 10):** "Multiestructural · Relacional y Abstracto Ampliado:
Los estudiantes podrán diseñar, implementar y analizar algoritmos básicos utilizando HTML5, CSS y
JavaScript, aplicando su conocimiento para resolver problemas del contexto del desarrollo web. Se
espera que comprendan la relación entre los conceptos de algoritmia y su aplicación práctica en
la creación de páginas web."

**Contenidos (p. 11-12):**
- Diseño de algoritmos: análisis del problema (descomposición en subproblemas, identificación de
  entradas y salidas); elección de estructuras de control (secuencial, condicional `if-else` /
  `switch`, iterativa `for` / `while` / `do-while`); diseño modular (funciones, procedimientos);
  pruebas de escritorio (verificación de la lógica del algoritmo).
- Implementación con HTML5, CSS y JavaScript: integración de JavaScript en páginas HTML;
  manipulación del DOM; eventos en JavaScript; validación de formularios.
- Herramientas de IA para el diseño e implementación de algoritmos: GitHub Copilot (generación de
  código asistida por IA); plataformas "low-code" (interfaces visuales y bloques de código
  predefinidos).

**Criterios de evaluación / indicadores (p. 11-18):**
- `RA-203413-U2-E1`: "Los estudiantes crearán una presentación interactiva utilizando HTML5 y
  CSS. La presentación debe contener al menos tres diapositivas que incluyan texto, imágenes y
  enlaces interactivos. Deberán aplicar HTML5 para estructurar la presentación y CSS para mejorar
  su calidad estética y visual."
- `RA-203413-U2-E2`: "Los estudiantes diseñarán un módulo educativo en línea utilizando HTML5 y
  CSS. El módulo debe contener al menos tres páginas con contenido educativo, como texto,
  imágenes y videos, y debe aplicar una estructura de navegación. Los estudiantes deberán
  asegurarse de que la calidad estética y visual mejore la experiencia del usuario."
- `RA-203413-U2-E3`: "Los estudiantes diseñarán un recurso educativo interactivo en línea, como
  un cuestionario, una simulación o un juego, utilizando HTML5 y CSS. El recurso debe ser
  funcional y atractivo visualmente. Deberán aplicar HTML5 para la interactividad y CSS para la
  mejora estética."

**Evidencias e instrumentos (p. 11):** Plantilla Web creada y publicada en el Repositorio en
GitHub · Documentación de ejercicios enviados a CINTIA · Prueba tipo Saber Pro.

---

### Unidad 3. Creación de OVA y REDA (p. 19-21) — 6 semanas

**Nivel de comprensión esperado (p. 19):** "Abstracto Ampliado: Los estudiantes podrán aplicar su
conocimiento de algoritmia y desarrollo web para crear OVAs y REDAs utilizando herramientas de
IA, teniendo en cuenta criterios de aprendizaje y técnicas de enseñanza. Se espera que comprendan
la importancia de la pedagogía en el diseño de recursos educativos digitales."

**Contenidos (p. 19-20):**
- OVA y REDA: definición, características, tipos; estándares de calidad y accesibilidad;
  herramientas de autoría para la creación de OVA y REDA.
- Integración de la IA en la creación de OVA y REDA: generación de contenido con IA (textos,
  imágenes, videos); creación de interfaces interactivas con chatbots de IA; personalización del
  aprendizaje con IA (sistemas de recomendación, rutas de aprendizaje adaptativas); herramientas
  de IA para la evaluación del aprendizaje.
- Desarrollo de OVA y REDA con HTML5, CSS y JavaScript: creación de animaciones e interacciones
  con JavaScript; uso de librerías y frameworks de JavaScript; integración de APIs de IA en
  páginas web educativas.

**Criterios de evaluación / indicadores (p. 19-20):**
- `RA-203413-U3-E1` ("Creación de OVA y REDA innovadores con algoritmia, desarrollo web e IA"):
  - *Diseño pedagógico:* "Documento en formato digital que describa el diseño pedagógico del
    OVA/REDA." + Rúbrica de evaluación.
  - *Desarrollo del OVA/REDA:* "Entrega del OVA/REDA en formato digital."
  - *Pruebas de usabilidad:* "Informe en formato digital que describa las pruebas realizadas, los
    resultados obtenidos y las mejoras implementadas."

**Evidencias e instrumentos (p. 19-20):** integradas en los tres entregables de `E1` arriba
(documento de diseño pedagógico + rúbrica, OVA/REDA entregado, informe de pruebas de usabilidad).
