# Guion — «Activa tu Tutor» (la mascota explica cómo sacar la clave de Google AI Studio)

Pedido del 17/11 (Pedro y Jeider): un video corto, con el Tutor explicando, para conseguir la clave sin perderse.
Voz: **Will** (ElevenLabs, modelo v3, cuenta gratuita), la misma del video de presentación; acelerada a 1,1× sin cambiar el tono (`assets/voz/willr_XX.mp3`).

| N.º | Escena | Lo que dice |
|---|---|---|
| 01 | hola | ¡Hola! Soy tu Tutor. Para ayudarte necesito una llave: una clave gratuita de Google. Te enseño a sacarla en dos minutos. |
| 02 | abrir | Primero, toca «Abrir Google AI Studio». Se abre en otra pestaña. Tranquilo: yo me quedo aquí esperándote. |
| 03 | entrar | Entra con tu cuenta de Google. Si es la primera vez, acepta sus condiciones. Es gratis y no pide tarjeta. |
| 04 | crear | Ahora toca «Create API key», que quiere decir crear clave. Si te pregunta por un proyecto, elige «Create API key in new project». |
| 05 | copiar | Aparece tu clave. Cópiala con el botón de copiar. Empieza por «AIza» o por «AQ punto». Es tuya: no se la pases a nadie. |
| 06 | pegar | Vuelve a STIRE, toca «Pegar» y después «Guardar y activar el Tutor». ¡Listo! Ya puedo ayudarte cuando un ejercicio no salga. |
