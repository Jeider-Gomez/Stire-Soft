# Análisis de las listas de chequeo

Los resultados de las dos listas del profesor, organizados para analizarlos y presentarlos. Cada documento responde una
pregunta:

| Documento | Pregunta que responde |
|---|---|
| [`CRITERIOS_Y_RESULTADOS.md`](CRITERIOS_Y_RESULTADOS.md) | ¿Qué pide cada uno de los 28 criterios y qué nota le puso el equipo como usuario? |
| [`ANTES_DE_LAS_LISTAS.md`](ANTES_DE_LAS_LISTAS.md) | ¿Cómo estaba STIRE el 04/10, de qué versión partimos y dónde se ve? |
| [`FALTA_PARA_V2.md`](FALTA_PARA_V2.md) | ¿Qué falta para cerrar la v2.0.0 y quién lo hace? |

**Las dos versiones para comparar:**

- Hoy: https://stire-soft.vercel.app
- Antes de las listas (04/10, commit `7c9977b`): https://stire-soft-b6ep923aj-lic-jeider.vercel.app (protegida en
  Vercel: ver cómo compartirla en [`ANTES_DE_LAS_LISTAS.md`](ANTES_DE_LAS_LISTAS.md) §1)

**Cómo se usa:** cada integrante lee sus criterios en `CRITERIOS_Y_RESULTADOS.md` para preparar su parte del pitch
(qué pide → antes → qué cambiamos → después). Las evaluaciones completas de cada fecha, con el Word del profesor, siguen
en las carpetas de fecha de [`../`](../README.md).
