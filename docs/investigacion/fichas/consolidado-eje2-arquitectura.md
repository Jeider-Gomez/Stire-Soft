## CS50 sandbox: secure execution of untrusted code

**Autores:** Malan, D. J.  
**Año:** 2013  
**Fuente:** Proc. 44th ACM SIGCSE, 141-146  
**Registro verificado:** DOI 10.1145/2445196.2445242

### Aporte a STIRE-Soft

Precedente de sandboxing pedagógico para ejecutar código de estudiantes de forma segura, referente para HardenedProcessSandboxAdapter (ADR 06).

## Smart Like a Fox: How Clever Students Trick Dumb Automated Programming Assignment Assessment Systems

**Autores:** Kratzke, N.  
**Año:** 2019  
**Fuente:** Proc. 11th CSEDU, 15-26  
**Registro verificado:** DOI 10.5220/0007424800150026

### Aporte a STIRE-Soft

Cataloga vectores de evasión en jueces automáticos; justifica el aislamiento real del sandbox frente a código adversarial.
