En el celular, el teclado también ocupa espacio

Cuando el teclado sube, se come media pantalla. Así queda el Tutor y el editor para que siempre se vea lo importante.

▲ Jeider, 06/11

Reglas

1. Con el teclado abierto, arriba queda una línea que recuerda dónde estás («línea 4: 2 * base + altura»).

2. El Tutor ofrece respuestas en botones («La suma», «No sé») para escribir menos.

3. El campo de texto y «Enviar» quedan pegados al teclado; también se puede dictar.

4. En el editor, la línea donde escribes se resalta y las teclas ( ) ; " = + * { } van sobre el teclado.

5. Al cerrar el teclado, todo vuelve a su tamaño sin saltos.
